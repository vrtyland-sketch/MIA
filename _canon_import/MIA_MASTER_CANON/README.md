# MIA MASTER CANON

Tento repozitář je zdroj pravdy pro architekturu, audit a implementaci projektu MIA.

## Práce v Cursoru

1. Rozbal složku do kořene projektu nebo jako `docs/MIA_MASTER_CANON/`.
2. Nech Cursor indexovat celý repozitář.
3. Otevři `CURSOR_AUDIT_PROMPT.md`.
4. Audit prováděj po jednom dokumentu nebo po jednom subsystému.
5. Výsledky zapisuj do `IMPLEMENTATION_MATRIX.csv`.
6. Kód měň až po označení konfliktů a vytvoření testovacího plánu.

## Stav balíku

- Migrované dokumenty: 0001–0049
- Dokument 0050: připraven jako další krok
- Plánovaný rozsah: až 5000 dokumentů
- Formát: Markdown + CSV + JSON manifest
