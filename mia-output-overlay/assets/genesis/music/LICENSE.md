# Genesis music / SFX

Place cleared audio files here when available:

- `music/startup.*`
- `music/ambient.*`
- `music/cyber.*`
- `music/calm.*`
- `music/diagnostics.*`
- `sfx/boot.*`, `confirm.*`, `error.*`, `reconnect.*`, `online.*`, `notification.*`, `loading.*`

Until files exist, `genesis-runtime.js` / `genesis-audio.js` use quiet WebAudio stubs.

Only use licensed / owned tracks.
