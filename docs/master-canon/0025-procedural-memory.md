## 1. Účel dokumentu

Procedural Memory je paměť dovedností MIA — schopnost něco vykonat. Odpovídá na otázku: **„Jak to mám udělat?"** Umožňuje zlepšování a automatizaci opakovaných činností.

---

## 2. Definice

Obsahuje pracovní postupy, algoritmy, strategie, návyky, sekvence akcí a automatizované rutiny. Každá dovednost může být postupně zdokonalována.

---

## 3. Architektura

```
PROCEDURAL MEMORY
├── Skill Library
├── Procedure Engine
├── Workflow Manager
├── Strategy Library
├── Macro Engine
├── Automation Engine
├── Optimization Engine
├── Skill Evaluator
├── Skill Versioning
├── Learning Pipeline
├── Procedure Index
├── Procedure Search
└── Procedural API
```

---

## 4. Hlavní princip

Vstup → Postup → Výsledek. Pokud lze činnost popsat opakovatelnými kroky, patří do Procedural Memory.

---

## 5. Skill Library

Naučené dovednosti: OBS, overlaye, Battle, grafika, API, Event Bus — každá s vlastním identifikátorem.

---

## 6. Procedure Engine

Procedura: název, účel, vstupy, předpoklady, kroky, očekávaný výsledek, podmínky ukončení. Znovupoužitelné.

---

## 7. Workflow Manager

Složené činnosti z více procedur — např. gift → body → miska → video → overlay → reakce → memory.

---

## 8. Strategy Library

Strategie rozhodování: Battle, spam, výkon, ekonomika, fronty — měnitelné bez zásahu do procedur.

---

## 9. Macro Engine

Často používané sekvence — např. restart OBS → kontrola → scény → test overlayů.

---

## 10. Automation Engine

Automatické vykonávání procedur při triggeru — např. OBS odpojen → připojení → kontrola → obnovení overlayů.

---

## 11. Optimization Engine

Vyhodnocení procedur: kroky, rychlost, úspěšnost, zdroje, chyby — podklad pro optimalizaci.

---

## 12. Skill Evaluator

Success Rate, Average Time, Error Rate, Usage Count, Reliability Score.

---

## 13. Skill Versioning

Verzované procedury — Battle Strategy v1 → v2 → v3, starší verze pro kompatibilitu.

---

## 14. Learning Pipeline

Nové procedury: ruční návrh, AI analýza, opakované použití, import, schválení adminem — vždy s validací.

---

## 15. Procedure Search

Vyhledávání podle názvu, oblasti, vstupu, výstupu, tagů, autora, verze, úspěšnosti.

---

## 16. Integrace s MIA

AI, Decision, Runtime, Battle, Kojnožrout, OBS, Overlay, Scheduler, Development.

---

## 17. Příklady procedur MIA

Reakce na gift, Battle workflow, Chat pipeline — vstup → kroky → výsledek.

---

## 18. Zakázané činnosti

Neukládat vzpomínky ani fakta, neobcházet Decision Engine, neměnit architekturu, nevytvářet nevalidované procedury.
