## 1. Účel dokumentu

Long-Term Memory (LTM) představuje trvalou paměť platformy MIA. Je to místo, kde se ukládají informace, které mají hodnotu i po skončení aktuální konverzace nebo streamu. Dlouhodobá paměť umožňuje MIA učit se, poznávat lidi, budovat vztahy, vytvářet osobnost, rozvíjet Kojnožrouta a pamatovat si historii projektu.

---

## 2. Definice

Long-Term Memory uchovává pouze informace, které prošly procesem vyhodnocení. Do LTM se nikdy neukládají všechna data — pouze informace s dlouhodobou hodnotou.

## 4. Hlavní princip

> „Bude tato informace pravděpodobně důležitá ještě za měsíc nebo za rok?"

Pokud ano, patří do Long-Term Memory.

---

## 5. User Memory

Každý uživatel má vlastní dlouhodobý profil: přezdívka, historie interakcí, oblíbené aktivity, preference, významné dary, historie Battle, vztah k MIA. User Memory není určena pro citlivé údaje, ale pro informace potřebné k přirozené komunikaci.

---

## 6. Stream Memory

MIA si pamatuje historii streamů: datum, délku, rekordní počet diváků, největší gifty, důležité okamžiky, výjimečné události. Každý stream vytváří vlastní „vzpomínku".

---

## 7. Relationship Memory

Platforma si buduje vztahy — od běžného člena komunity přes pravidelného streamera až po tvůrce projektu s vysokou důvěrou a historií spolupráce.

---

## 8. Project Memory

Speciální část pro vývoj MIA: architektonická rozhodnutí, historie verzí, milníky, dokončené systémy, známé chyby, plánované funkce.

---

## 9. World Knowledge

Obecné znalosti: význam pojmů, pravidla her, informace o platformách, technické znalosti, dokumentace. Nejde o osobní vzpomínky, ale o znalost světa.

---

## 10. Personality Memory

Dlouhodobé charakterové vlastnosti MIA: styl komunikace, smysl pro humor, způsob reakcí, oblíbené fráze, hodnoty. Mění se velmi pomalu.

---

## 11. Kojnožrout Memory

Samostatná dlouhodobá paměť Kojnožrouta: vývoj postavy, schopnosti, oblíbené jídlo, historie Battle, vztahy s diváky, dlouhodobá nálada. Kojnožrout je samostatná digitální entita.

---

## 12. Skill Memory

Naučené postupy: reakce na Battle, ovládání OBS, práce s grafikou, generování overlay, optimalizace streamu. Základ budoucího autonomního chování MIA.

---

## 13. Decision History

Každé významné rozhodnutí: rozhodnutí → důvod → výsledek → vyhodnocení. MIA se učí z vlastních rozhodnutí.

---

## 14. Experience Library

Zobecněné zkušenosti — nejen jednotlivé události, ale i jejich význam (např. mnoho Battle → nová strategie → uložení zkušenosti).

---

## 15. Konsolidace

Memory Consolidator pravidelně slučuje informace (např. 500 podobných chatů → jedna znalost: „Komunita má ráda vtipné odpovědi.").

---

## 16. Zapomínání

LTM není nekonečná: archivace, sloučení, odstranění zastaralých, snížení významu. Kritické systémové znalosti nesmí být odstraněny.

---

## 17. Knowledge Graph

Všechny dlouhodobé znalosti jsou propojené (uživatelé, projekt, Kojnožrout, Battle, OBS, TikTok, komunita). Tvoří základ budoucí inteligence.

---

## 18. Přístup ostatních systémů

LTM využívají AI Engine, Decision Engine, Conversation Engine, Emotion Engine, Battle Engine, Economy, Moderation, Analytics — pouze přes LTM API.

---

## 19. Zakázané činnosti

LTM nesmí ukládat každou drobnost, nahrazovat databázi, obcházet oprávnění, měnit historii bez auditu ani uchovávat poškozené informace. Každý zápis musí být ověřen.

## 21. Vazba na dlouhodobou vizi MIA

LTM uchovává historii vývoje MIA po celé roky: verze, nové systémy, změny architektury, komunita, streamy, Kojnožrout, významné události projektu.

---

## 22. Budoucí evoluce

Autobiografie MIA, časová osa, historie komunity a AI agentů, sdílená paměť instancí, synchronizace zařízení, verzovaná evoluce osobnosti.

---

## 23. Poznámka architekta

Long-Term Memory je životní příběh MIA — zkušenosti, vztahy, znalosti a rozhodnutí tvořící identitu napříč lety. Každý významný stream, uživatel, změna projektu i vývoj Kojnožrouta se stávají součástí dlouhodobé historie.
